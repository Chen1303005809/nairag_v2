# 关系型数据库
##  `knowledge_entry`：知识条目主表

| 字段                   | 类型               | 说明                             | 是否嵌入 |
| -------------------- | ---------------- | ------------------------------ | ---- |
| `entry_id`           | `VARCHAR(128)`   | 主键；Milvus 回查关系库的唯一标识           |      |
| `entry_key`          | `VARCHAR(128)`   | 大类父键                           |      |
| `collections`        | `TEXT`           | 集合id                           |      |
|                      |                  | 问题大类                           |      |
| `canonical_keyword`  | `VARCHAR(255)`   | 条目的主关键词                        |      |
| `lexical_rules_json` | `JSON/TEXT`      | 别名、词法匹配词和正则规则                  |      |
| `status`             | `VARCHAR(20)`    | `draft`、`published`、`archived` |      |
| `version`            | `INTEGER`        | 每次内容变更递增；用于触发重新索引              |      |
| `created_at`         | `TIMESTAMP`      | 创建时间                           |      |
| `updated_at`         | `TIMESTAMP`      | 更新时间                           |      |
| `published_at`       | `TIMESTAMP NULL` | 发布时间                           |      |
| `created_by`         | `VARCHAR(128)`   | 创建人                            |      |
| `updated_by`         | `VARCHAR(128)`   | 修改人                            |      |


## `Knowledge_child` 知识条目子表

| 字段                       | 类型               | 说明                             | 是否嵌入 |
| ------------------------ | ---------------- | ------------------------------ | ---- |
| `entry_id`               | `VARCHAR(128)`   | 主键；Milvus 回查关系库的唯一标识           |      |
| `entry_key`              | `VARCHAR(128)`   | 小类子键                           |      |
| `question_variants_json` | `JSON/TEXT`      | 同义问句列表；唯一的当前向量来源               | 嵌入   |
| `response_content`       | `TEXT`           | 最终回复内容；初始化默认“转研发查询”            | 嵌入   |
| `follow_up_guidance`     | `TEXT NULL`      | 命中后需要澄清、收集或执行什么的自由文本指引         |      |
| `question`               | `TEXT`           | 问题细则                           | 嵌入   |
| `type`                   | `VARCHAR(255)`   | 问题类型                           |      |
| `object`                 | `VARCHAR(255)`   | 业务对象                           |      |
| `purpose`                | `VARCHAR(255)`   | 使用目的                           |      |
| `customer_type`          | `VARCHAR(255)`   | 客户类型                           |      |
| `feature_explanation`    | `TEXT NULL`      | 功能说明                           |      |
| `example`                | `TEXT NULL`      | 示例                             |      |
| `notes`                  | `TEXT NULL`      | 内部备注                           |      |
| `attachments_json`       | `JSON/TEXT`      | 图片、文件等附件                       |      |
| `web_links_json`         | `JSON/TEXT`      | 相关网页链接                         |      |
| `status`                 | `VARCHAR(20)`    | `draft`、`published`、`archived` |      |
| `version`                | `INTEGER`        | 每次内容变更递增；用于触发重新索引              |      |
| `created_at`             | `TIMESTAMP`      | 创建时间                           |      |
| `updated_at`             | `TIMESTAMP`      | 更新时间                           |      |
| `published_at`           | `TIMESTAMP NULL` | 发布时间                           |      |
| `created_by`             | `VARCHAR(128)`   | 创建人                            |      |
| `updated_by`             | `VARCHAR(128)`   | 修改人                            |      |
| `hit_count`              | `BIGINT`         | 命中次数；后续可扩展，添加redis             |      |


# 向量数据库
## Milvus Schema

| 字段               | Milvus 类型            | 说明                           |
| ---------------- | -------------------- | ---------------------------- |
| `id`             | `INT64`，主键，`auto_id` | Milvus 内部主键                  |
| `entry_id`       | `VARCHAR(128)`       | 回查 `knowledge_entry`         |
| `version`        | `INT64`              | 对应 `knowledge_entry.version` |
| `source_item_id` | `INT64`              | 多个元素嵌入时的分片编号                 |
| `field_type`     | `VARCHAR(64)`        | 必填、受控类型，如 `question_variant` |
| `field_text`     | `VARCHAR(65535)`     | 单一语义的分片原文                    |
| `weight`         | `FLOAT`              | 该类型的召回权重                     |
| `text_embedding` | `FLOAT_VECTOR(1024)` | 文本向量                         |
| `vl_embedding`   | `FLOAT_VECTOR(2048)` | 仅保留现有图片检索能力时需要               |
