# 父类全局化，子条目按知识库发布

父类只表示全局问题大类，不绑定知识库；知识库差异由 `子条目 × 知识库` 发布关系及其当前修订表达。每个父类唯一的主子条目负责把父类知识投放到一个或多个知识库，检索结果再以全局父类为一级、各知识库当前子条目为二级展示。该设计避免复制父类造成分类漂移，同时允许同一子条目在不同知识库独立审核、归档和生效不同修订。

## Consequences

- 禁止父类保存 `collection_id` 或 `collections` 字段。
- 普通子条目只能投放到其主子条目已经发布的知识库。
- 父类—主子条目修订必须在全部相关知识库通过后全局一致切换；普通子条目仍按知识库独立切换。
- 不得按 Collection 复制父类结果，也不得对不同知识库的子条目做跨库去重。
